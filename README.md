# Presupuesto Mensual – Desafío Práctico 1
 
Aplicación web para registrar ingresos y egresos de un mes y calcular el porcentaje de gastos con respecto a los ingresos.
 
Lenguajes Interpretados en el Cliente (LIC941) – Universidad Don Bosco
 
## Funcionalidades
 
- Título con el mes y año actuales.
- Saldo disponible (ingresos − egresos).
- Totales de ingresos, egresos y porcentaje global de gastos.
- Formulario para agregar transacciones con validación de campos.
- Pestañas para ver ingresos y egresos, con el porcentaje de cada egreso.
- Eliminación de transacciones.
  
## Tecnologías 
- HTML5
- CSS3
- JavaScript (sin librerías ni frameworks)
- Bootstrap 4
